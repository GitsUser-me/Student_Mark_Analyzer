
# Student Marks Analyzer

A beginner-friendly Data Science mini-project built using Python, Pandas, and Matplotlib.

## Features

- Reads student marks from a CSV file.
- Calculates total and average marks.
- Identifies the student with the highest total marks.
- Classifies students as Pass or Needs Improvement.
- Displays a bar chart of student total marks.
- Exports the analysis report to a CSV file.

## Technologies Used

- Python
- Pandas
- Matplotlib

## Project Files

- `main.py` — Main Python program.
- `students.csv` — Sample student marks dataset.
- `student_report.csv` — Generated analysis report.
- `requirements.txt` — Required Python packages.
- `.gitignore` — Files excluded from Git tracking.

## Installation

Install Python 3.12 or a compatible Python version.

Install the required packages:

```bash
python -m pip install -r requirements.txt
```

## Run the Project

Run this command from the project folder:

```bash
python main.py
```

The program displays student analysis and opens a bar chart. It also generates `student_report.csv`.

## Learning Objectives

This project demonstrates basic data handling, calculations, conditional logic, CSV file processing, and data visualization.
